# Next.js + TypeScript

This template provides a minimal Next.js App Router setup with TypeScript.

Currently, two official plugins are available:

- App Router for file-based routing in the `app` directory
- TypeScript support for typed React components and configuration

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
